## 사용한 이미지
- 대표 이미지: `01_앱아이콘_512x512.png`
- 상세 이미지: 실기기 캡처 `01_촬영지추천` / `02_장소상세` / `03_지도` + 촬영 가이드(에뮬레이터)
- 흐름도: 위 실기기 캡처의 부분 확대 + 카테고리 필터·구도 가이드는 무무 플레이어 캡처

## 기능설명서에서 확인할 것
- [x] 표지 팀명: 김영석
- [ ] 촬영 가이드 캡처(슬라이드 4·9)는 무무 플레이어에서 앱 내장 데모 배경(디버그 전용) 위에 가이드를 얹은 화면입니다.
      가이드 렌더링 자체는 실제 동작이지만 배경은 카메라 실시간 영상이 아니므로, 실기기 촬영본으로 교체하면 더 좋습니다.
      (`스크린샷/원본캡처/04_촬영가이드_원본.png` 은 실제 카메라 촬영본이나 구버전 빌드라 안내 문구가 현재와 다릅니다)

## 콘텐츠랩 입력 항목 (기능설명서와 별개)
1. 팀 정보 — 최종 팀원 확정 입력 (팀원 전원 사전 회원가입 필요)
2. 서비스 정보
   - 서비스명: 정읍 시선 (PicView)
   - 서비스 유형: 앱
   - 지역 특화: 있음 / 전북특별자치도 정읍시  ← 가점 2점 항목
3. 서비스 테스트 정보
   - [ ] 서비스 URL: https://play.google.com/store/apps/details?id=com.youngs.picview
         (프로덕션 트랙 심사 승인 + 출시 완료 후 접속 가능)
   - [x] 테스트 계정: **로그인 불필요** — 본 앱은 로그인 절차가 없으므로 '로그인 불필요' 선택
4. 한국관광공사 OpenAPI 활용 정보
   - [ ] 공공데이터포털 인증키(인코딩/디코딩) 제출
   - [ ] **운영계정 신청 필수** — 대표 1개 API(국문 관광정보 서비스_GW) 기준
5. 기능설명서 PDF 업로드
