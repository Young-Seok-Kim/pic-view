## 2.7 (versionCode 9) — 2026-09-18

### 스토어 출시 노트

```
· 촬영 화면의 구도 가이드(격자)를 끄면 앱을 쓰는 동안은 그대로 기억하고,
  앱을 새로 켜면 다시 켜진 채로 시작합니다.
```

### 바뀜

- **격자 기억 방식** — 2.6 은 카메라를 열 때마다 격자를 켰습니다. 한 촬영에서
  끄고 다음 장소로 옮기면 또 꺼야 해서, 앱을 켜 있는 동안은 끈 상태를 기억하고
  앱을 새로 켤 때만 켜진 채로 시작하도록 바꿨습니다. 디스크에는 저장하지
  않으므로 예전처럼 며칠 뒤까지 꺼진 채로 남는 일은 없습니다.

## 2.6 (versionCode 8) — 2026-09-18

### 스토어 출시 노트

```
· 휴대폰이 다크 모드여도 앱이 밝은 화면 그대로 보이도록 고쳤습니다.
  처음 실행 안내에서 "일반 글씨로 볼게요" 버튼 글씨가 안 보이던 문제가 없어졌습니다.
· 처음 실행 안내에서 큰 글씨를 고르거나 화면이 작은 기기에서 제목·안내 문구가 잘리던 문제를 고쳤습니다.
· 촬영 화면의 구도 가이드(격자)가 한 번 끄면 계속 꺼진 채로 남던 문제를 고쳤습니다.
  이제 카메라를 열 때마다 켜진 채로 시작합니다.
```

### 고침

- **다크 모드에서 글씨가 사라지던 문제** — 앱은 크림 톤 라이트 디자인 하나로
  고정입니다. 시스템 다크 모드를 따라가면서 배경은 검게, 글자는 희게 바뀌었는데,
  처음 실행 안내 3장의 보기 모드 버튼은 배경을 연한 베이지로 박아 두어 그 위의
  흰 글씨가 안 보였습니다. 이제 다크 모드를 따라가지 않고, 이 버튼의 배경·글자색은
  선택/미선택 각각 고정 색으로 둡니다.
- **처음 실행 안내가 잘리던 문제** — 큰 글씨를 고르거나 화면이 작은 기기에서
  3장의 제목이 위로, 하단 안내 문구가 아래로 잘렸습니다. 글이 길어지면 가운데
  사진이 그만큼 줄어들고(최소 높이까지), 그래도 안 들어가면 스크롤됩니다.
  4장 모두 같은 방식입니다.
- **촬영 화면 격자가 안 보이던 문제** — 격자 버튼으로 한 번 끄면 그 상태가
  저장되어, 어느 경로로 카메라를 열어도 격자가 없었습니다. 이제 카메라를 열
  때마다 켜진 채로 시작하고, 끄는 것은 그 촬영 동안만입니다.

## 2.5 (versionCode 7) — 2026-09-15

### 바뀜

- **거리 기준을 전부 내 위치로** — 탐색의 거리순 정렬, 카드의 "차로 N분",
  코스 장소 고르기, 지도 시트, 포토스코어의 접근성 항목이 모두 한 출발점
  (내 위치)에서 잽니다. 전에는 화면마다 기준이 달라 같은 장소가 다른 거리로
  나왔습니다. 위치를 모르면 시내 기준으로 물러나고 문구도 "시내에서"로 밝힙니다.
- **위치 권한** — 켤 때 한 번 묻고, 화면 복귀·당겨서 새로고침 때 다시 잽니다.
  위치가 늦게 잡히면 접근성 점수만 다시 매겨 추천순을 갱신합니다.
- **탐색 카드** — 하트·카메라를 제목 줄 오른쪽으로 옮기고, 긴 제목은 흐르게
  했습니다. 카메라는 그 장소의 촬영 시작(앱 카메라)으로 바로 이어집니다.
- 긴 이동 시간은 "N시간 M분"으로 접어 표시합니다.

## 2.4 (versionCode 6) — 2026-09-14

### 크래시

- 포토 프레임에서 색감 필터를 적용한 뒤 네컷으로 전환하면 죽던 문제
- 카메라 초기화·바인딩·촬영 실패를 안내하고 죽지 않게

### 고침

- 탐색: 정렬을 바꿔도 목록이 정렬 전 첫 카드를 붙잡고 있던 문제
- 코스: 저장한 코스를 다시 짠 뒤 저장이 눌리지 않던 문제, 다시 짤 때 다른
  장소로 바뀌던 문제, 일정 저장이 같은 코스를 거듭 쌓던 문제
- 상세: 점수 없는 장소에서 장소 정보가 펴지지 않던 문제, 요약과 전문이 겹치던 문제
- 점수: 해 방향을 지금 빛 구간에서 계산, 내장산 계절 판정
- 지도 시트의 찜 상태, 캘린더의 계절 선택, 미션의 포토스코어 저장, 문구 여러 곳
- 촬영 화면에서 구도 가이드를 끄면 안내 문구·포즈 목록도 함께 감춥니다
