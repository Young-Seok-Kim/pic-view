# 플레이스토어 등록 에셋

구글 플레이 콘솔에 그대로 올릴 수 있는 크기로 맞춰 둔 것들입니다.
모두 앱 아이콘 원본 한 장에서 만들어져 톤이 서로 어긋나지 않습니다.

## 파일

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `ic_launcher-512.png` | 512×512 | 앱 아이콘 (32비트 PNG, 알파 없음) |
| `feature-graphic-1024x500.png` | 1024×500 | 그래픽 이미지 (스토어 상단 배너) |
| `phone/01~08.png` | 1080×1920 | 휴대전화 스크린샷 8장 (9:16) |

## 스크린샷을 이 순서로 둔 이유

스토어에서 사람이 끝까지 넘겨 보는 장수는 두세 장입니다. 그래서
**"이 앱이 남과 무엇이 다른가"** 가 먼저 나오도록 놓았습니다. 예쁜
화면이 아니라 *빛을 계산한다* 는 것이 드러나는 화면부터입니다.

1. **홈** — 지금의 빛과 오늘의 빛 흐름. 이 앱의 전제가 첫 장에 나옵니다
2. **탐색** — 빛이 맞는 촬영지. "어디를"이 아니라 "언제 어디를"
3. **코스** — 골든아워를 먼저 예약하고 나머지를 채운 타임라인
4. **직접 고르기** — 장소는 내가, 순서는 빛이
5. **시선 가이드** — 날씨 탭이 사진·구도·팁을 한꺼번에 바꿉니다
6. **상세** — 출사 적합도 게이지와 그 자리에서 할 미션
7. **지도** — 관광 분류가 아니라 촬영 목적으로 나눈 마커
8. **MY** — 로그인 없이 기기 안에 쌓이는 기록

## 다시 만들 때

원본 아이콘 한 장(1024×1024 정사각 PNG)만 있으면 전부 다시 나옵니다.
스크립트는 `docs/store` 밖에 두지 않았고, 만들 당시의 절차는 이렇습니다.

1. 원본에서 흰 여백을 걷어내고 정사각으로 맞춤
2. 512 로 줄여 아이콘, 432 로 줄여 적응형 아이콘 배경
   (`res/drawable-nodpi/ic_launcher_scene.png`)
3. 각 dpi 런처 PNG 는 둥근/원형 마스크를 씌워 생성
4. 배너는 원본의 **위쪽 띠(하늘·해·능선)** 만 잘라 가로로 늘림 —
   아래쪽에는 카메라 윤곽이 크게 얹혀 있어 그대로 쓰면 배너 밑에
   흰 선이 유령처럼 비칩니다
5. 스크린샷은 무무 플레이어(900×1600, 정확히 9:16)에서 찍어 1080×1920 으로 확대

## 주의

- 아이콘 PNG 에 **알파 채널을 넣으면 반려**됩니다. `ic_launcher-512.png`
  는 RGB 로 저장돼 있습니다
- 배너에는 스토어가 앱 이름을 따로 얹지 않습니다. 여기 적힌 글자가 곧
  첫인상이므로 문구를 바꿀 때는 배너도 함께 고쳐야 합니다
